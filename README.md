# Peel — Free Background Remover

Remove image backgrounds in the browser. Transparent PNG or a solid backdrop.

- 100% client-side (`onnxruntime-web` + U²-NetP + Canvas). The photo never leaves this tab.
- No signup, no watermark, no daily limit.
- Live: [bg-local.vercel.app](https://bg-local.vercel.app)

## Privacy

Photos are processed only in memory. The on-device model is a static file from this origin — not an upload of your image.
